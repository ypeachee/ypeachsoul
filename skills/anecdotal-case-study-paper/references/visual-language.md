# Visual language

## Principles

- One figure, one argument.
- Use the simplest chart that exposes the comparison.
- Label the reference frame and unit.
- State the source and inferential limit in the caption.
- Mark conceptual figures as metaphors.
- Do not make an illustrative chart look like measured data.
- Prefer vector-native diagrams or high-resolution PNGs.

## Useful figure types

### Timeline

Use for disputed appointments, promised durations, or sequence-dependent events. Show the external timeline and the reported/subjective timeline as separate tracks.

### Log-scale comparison

Use when ratios vary by orders of magnitude. Label the unit and explain why a log scale is needed.

### Concept or mechanism diagram

Use for metaphors such as a "gravity well," "black hole," or "time field." Draw the metaphor clearly, but include a note such as:

> This figure is a conceptual metaphor, not a physical model.

### Compression chart

Use for long-period versus short-period tasks. If one segment is expanded for readability, say so.

### Evidence radar

Use for a subjective evidence profile only when the scores are explicitly described as researcher judgments. Do not present the polygon as a statistical estimate.

### Hypothesis map

Use to show which evidence supports, weakens, or fails to distinguish competing explanations. Make "untested" and "cannot exclude" visible.

## The metaphor figure

A strong metaphor figure should contain:

- a recognizable physical scene;
- a clear mapping between visual elements and behavioral mechanisms;
- a short equation-like annotation only when it is explicitly a joke or bookkeeping device;
- a caption that states what the figure does not prove.

Example mapping:

- bed = potential well;
- morning intention = light path;
- delay = geodesic deflection;
- sleep inertia, phone use, and task aversion = friction terms.

## Captions

A formal caption should include:

- figure number and title;
- what is plotted or depicted;
- data source;
- assumption or limitation.

Example:

> Figure 3. Conceptual illustration of the blanket gravity well. The 5-hour shift is a behavioral observation, not a relativistic measurement. Source: observer notes.

## Tables

Use three-line tables in formal output:

- top rule;
- header rule;
- bottom rule;
- no vertical lines;
- caption above the table;
- note below the table.

Renumber every table and figure after insertion or deletion. Search the manuscript for stale references such as "Figure 4" after Figure 3 has been removed.

## Transcript material

Do not use a chat screenshot as a default figure. Prefer:

- a short prose reconstruction;
- a text-only quote block;
- an evidence-table row;
- an appendix with redacted text.

Follow the user's explicit exclusion. If a transcript image is removed, renumber the remaining figures and update all in-text references.
