# 荣格八维与职业定位映射说明

结果页的“荣格八维倾向”是 V4.1 新增的解释层。它不改变原有 30 题题库和主副原型评分，只把 8 个原型答案映射成 8 个认知功能分数。

## 原型映射

| 荣格功能 | 原型 | 解释重点 |
|---|---|---|
| Ni 内倾直觉 | 观星者 | 把分散线索收束成长期方向 |
| Ne 外倾直觉 | 织梦者 | 从可能性中生成新的连接 |
| Ti 内倾思考 | 架构师 | 建立内部一致的结构与原则 |
| Te 外倾思考 | 探路者 | 把目标转成可执行系统 |
| Fi 内倾情感 | 炼金者 | 依据内在价值判断什么重要 |
| Fe 外倾情感 | 守火者 | 读取并调节关系中的温度 |
| Si 内倾感觉 | 深潜者 | 从经验与细节中确认稳定感 |
| Se 外倾感觉 | 逐风者 | 在当下快速感知并行动 |

## 结果生成

1. 统计 8 个原型在 30 题中的选择次数。
2. 将原型分数一对一映射为荣格八维分数。
3. 分数最高的功能为主功能，第二高为辅助功能，最低为压力盲区。
4. 根据主功能选择职业方向模板，根据主功能与辅助功能组合生成职场定位摘要。
5. 输出 3 个职业方向、岗位示例、团队价值、环境匹配、风险提示与一个 7 天验证实验。

八维分数不会保存为新的用户数据，也不上传服务器；结果由当前已保存的本地答案确定性生成。

## 边界

- 不是正式 MBTI 测评，也不等同于荣格临床理论。
- 不是能力测试、职业资格判断、录用建议或薪资预测。
- 职业方向是探索假设，不是对个人上限的定义。
- 当前题目并非专门为八维测评设计，因此结果只能视为文化解释与自我观察入口。
